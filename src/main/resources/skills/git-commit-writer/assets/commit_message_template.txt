## 模板 A：单主题提交

<type>: <一句话概括改动>

- <为什么改 / 背景>
- <关键实现点>
- <影响面或注意事项>

## 模板 B：多主题提交（一个 commit 含多个独立主题）

<type>: <总体概括，用逗号串联各主题>

1) <type>: <主题一>
- <要点>
- <要点>

2) <type>: <主题二>
- <要点>

3) <type>: <主题三>
- <要点>

## 模板 C：拆分提交建议（每个主题一个 commit）

【提交 1】git add <路径1> <路径2>
<type>: <主题一>

【提交 2】git add <路径3>
<type>: <主题二>

【提交 3】git add <路径4>
<type>: <主题三>
